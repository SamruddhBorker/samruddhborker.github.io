# samruddhborker.github.io

Portfolio page and example sites for Samruddh Borker's website service for Goa businesses.

Live at https://samruddhborker.github.io/

## What's here

- `index.html`, `css/site.css`: the portfolio page, plain HTML and CSS with no build step or JavaScript
- `demos/homestay/`: Casa Mangueira, a fictional homestay
- `demos/academy/`: Mhadei Classes, a fictional coaching centre
- `demos/cafe/`: Coastal Café, a fictional café

Each demo is a copy of [business-website-template](https://github.com/SamruddhBorker/business-website-template), which is how a client site starts too. All three businesses are fictional, carry a visible demo label and are marked `noindex`. Demo photos are hotlinked from [Pexels](https://www.pexels.com/license/).

## Run locally

```bash
php -S 127.0.0.1:8086
```

Then open http://127.0.0.1:8086.
